Command-line tool and Go library

Search Arabic-script text across diacritics, spelling variants, and ligatures.

grep and ripgrep compare bytes, so a search for مدرسه misses مَدْرَسَة, text copied from a PDF, and the Persian spelling. agrep normalizes the query and each line before comparing them, prints the original line, and reports where the match is in it.

Comparison

The same query in grep and agrep

grep looks for the query bytes. agrep compares normalized text and highlights the match in the original line.

Standard grep / ripgrep
$ grep 'مدرسه' corpus.txt
(no match: the text has vowel marks)
0 matches
agrep (Arabic-script aware)
$ agrep 'مدرسه' corpus.txt
هذه مَدْرَسَةٌ عريقة في المدينة.
1 match · bytes [7:27]
The default profile folds ة to ه and removes the vowel marks (fathah, dammah, tanwin) before comparing. The highlighted word is the original text, vowels included.

Features

What agrep handles

Each feature below has a CLI flag and a matching option in the Go packages.

01 / NORMALIZATION

Normalization profiles

Five profiles built on Unicode NFD (search, strict, loose, lucene, camel), plus flags to keep or fold individual kinds of marks and letters.

Normalization →
02 / LANGUAGES

Six Arabic-script languages

Arabic, Persian, Urdu, Pashto, Sorani Kurdish, and Uyghur. One language keeps its own letters; Arabic plus another language also folds shared letters such as ک and ك.

Languages →
03 / MANUSCRIPTS

Rasm and fuzzy matching

Search unpointed manuscripts, where ب ت ث ن ي share the skeleton ٮ. --fuzzy allows a set number of edits for typos and OCR errors.

Matching →
04 / ACCURACY

Offsets in the original text

Matching runs on normalized text, but every span is reported as byte offsets in the original line. A match inside the ligature ﻻ covers the whole ligature.

JSON output →
05 / ENCODINGS

Legacy encodings and transliteration

Reads CP1256, ISO-8859-6, and UTF-16, and can detect which one a file uses. Queries can be typed in Buckwalter, ArabTeX, or ISO 233 transliteration.

Encodings →
06 / EMBEDDABLE

Go packages

The CLI is built on three importable packages: arabic for normalization, match for matchers, and scan for streaming line search.

Go library

Use it from Go

The CLI's normalization and matching code is available as Go packages.

Go 
package main

import (
    "fmt"

    "github.com/MohamedElashri/agrep/arabic"
    "github.com/MohamedElashri/agrep/match"
)

func main() {
    // 1. Normalization collapses diacritics and spelling variants
    p := arabic.ProfileSearch
    key1 := p.Normalize("مَدْرَسَةٌ")
    key2 := p.Normalize("مدرسه")
    fmt.Println(key1 == key2) // true

    // 2. Fuzzy search, with the match mapped back to the original text
    m, _ := match.NewFuzzy([]string{"كتاب"}, p, false, 1)
    text := "هذا كتلب جديد"
    normKey, idx := p.NormalizeMapped(text)
    for _, span := range m.FindAll(normKey) {
        start, end := arabic.MapSpan(idx, span.Start, span.End)
        fmt.Printf("Matched %q at [%d:%d]\n", text[start:end], start, end)
    }
}
