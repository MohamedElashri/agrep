Unicode-aware search tool

Ultrafast, Unicode-aware search for Arabic-script text.

Standard tools like grep and ripgrep miss matches due to vocalization diacritics, presentation-form ligatures, letter variants, and diverse orthographies. agrep eliminates search blind spots with zero-allocation streaming normalization, dotless rasm reconstruction, and exact source byte mapping.

Interactive Comparison

Why generic search fails on Arabic

Arabic orthography requires normalization before matching. Standard grep tests raw bytes; agrep normalizes in memory while pointing back to the exact source bytes.

Standard grep / ripgrep
$ grep 'مدرسه' corpus.txt
(No match found — diacritics block exact byte search)
0 matches (missed text)
agrep (Arabic-script aware)
$ agrep 'مدرسه' corpus.txt
هذه مَدْرَسَةٌ عريقة في المدينة.
Match found · exact byte span [4:24]
How it works: The query مدرسه automatically folds ta-marbuta (ة → ه) and strips vocalization diacritics (fathah, dammah, tanwin) during normalized key comparison, while preserving original source text and exact UTF-8 byte spans.

Technical Architecture

Designed for linguistic precision and throughput

agrep combines the linguistic correctness of specialized NLP packages with the streaming speed of modern system utilities.

01 / NORMALIZATION

Streaming Unicode Normalization

Zero-allocation Unicode NFD pipeline supporting 5 standard presets (search, strict, loose, lucene, camel) and granular flags to keep or fold specific marks.

02 / LANGUAGES

Six Arabic-Script Languages

First-class support for Persian (Farsi), Urdu, Pashto, Sorani Kurdish, and Uyghur. Retains distinct language alphabets or enables shared letter search across Arabic and Persian.

Read Language Support →
03 / MANUSCRIPTS

Dotless Rasm & Myers Fuzzy

Search unpointed historical manuscripts where ب ت ث ن ي share the dotless skeleton ٮ. Bit-parallel Myers algorithm handles typos, dialect variance, and OCR errors.

Read Matching Docs →
04 / ACCURACY

Exact Source-Byte Spans

Matches on normalized keys, but maps every span back to original text UTF-8 byte offsets. Even expanded presentation forms like ﻻ map back to the single source character.

Legacy Encodings & Transliteration

Automatic detection for CP1256, ISO-8859-6, and UTF-16. Search Arabic corpora from a Latin keyboard using standard Buckwalter, ArabTeX, or ISO-233 transliteration schemes.

Embeddable Library

Import into your Go application

Integrate Unicode-aware Arabic normalization and matching directly into your Go services and pipelines.

Go 
package main

import (
    "fmt"
    "github.com/MohamedElashri/agrep/arabic"
    "github.com/MohamedElashri/agrep/match"
)

func main() {
    // Normalization collapses diacritics and spelling variants
    p := arabic.ProfileSearch
    key1 := p.Normalize("مَدْرَسَةٌ")
    key2 := p.Normalize("مدرسه")
    fmt.Println(key1 == key2) // true

    // High-performance Myers fuzzy search
    m, _ := match.NewFuzzy("كتاب", 1, p)
    matches := m.FindAll("هذا كتلب جديد", -1)
    fmt.Printf("Matched %d spans\n", len(matches))
}
